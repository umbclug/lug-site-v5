Hey Retrievers!

You've probably heard some of us yap about the mirror server that we run, come learn more about it.

## Server Building 101
**Today at 7:15 PM in PAHB 108** (Not our normal meeting location!)

Ever wondered what it takes for LUG to run a production mirror server, or what makes an enterprise server different from the Optiplex hosting a minecraft server in your basement? We'll discuss what makes a server a server and the different kinds of technologies used in production environments.

- Find out what's inside an enterprise server
- Learn what it takes to maintain a production server
- Learn about the LUG mirror server
- Get a chance to see and work on real decommissioned enterprise servers similar to the ones we run the mirror with

**There will be free pizza!** No experience needed, this is a great chance to invite your friends.

Through this event we have also received funding for major server upgrades for the mirror, ensuring its long-term stability. Stay tuned for more information about that in our Discord's mirror-announce channel.

Help us get to the top of myUMBC by giving our [event](https://my3.my.umbc.edu/groups/lug/events/160104) a paw!

The swap meet still remains a great way to get your hands on some neat hardware, and they run a repair workshop directly afterwards.
