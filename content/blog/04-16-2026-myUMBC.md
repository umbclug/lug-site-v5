## LUG's Mirror Public Server Enters Production
Hey Retrievers! 

Over the past couple months, Linux Users Group's system administration team has been working diligently setting up a public repository mirror service. We aim to provide open, reliable, high speed access to a variety of popular Linux distributions for the Linux and open-source community. 

The mirror server is now entering production, and is open to the general public for use. We support downloading via HTTP(s) and RSYNC (details below). We currently have 8 distributions mirrored (including Debian, Arch, Ubuntu, Mint, etc), with more coming soon! To utilize our mirror server for your distribution, consult the documentation for your distros package manager for instructions on how to set our server as your mirror!

Accessing the mirror:

- HTTPS: https://mirror.lug.umbc.edu
- HTTP: http://mirror.lug.umbc.edu
- RSYNC: rsync://mirror.lug.umbc.edu

Feel free to join our Discord server for more information, or check out our website! Links to both are below:

[LUG Website](https://lug.umbc.edu/) | [Discord Server](https://sh.lug.umbc.edu/discord) | [Mirror Server](https://mirror.lug.umbc.edu)
